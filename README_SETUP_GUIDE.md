## 3. خطوات التنفيذ

### 3.1 التنفيذ المباشر
1. **تنفيذ التكوين:**
   - تشغيل `python.exe GM_ChatGPT_Config.py`
   - يؤدي إلى تنشيط مدير العام في ChatGPT

2. **تشغيل الخادم:**
   - تشغيل `start_gm.bat` (أو `python.exe orchestrator.py`)
   - يستمع على `ws://127.0.0.1:8799`

3. **تنفيذ المهام الحقيقية:**
   - تشغيل `python.exe execute_real_project_task.py`
